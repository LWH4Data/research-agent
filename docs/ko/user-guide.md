# Research Agent 사용 안내

설치부터 PDF 정리, 검색, 대화 저장까지의 설명은
[한국어 README](../../README.md)에 모아 두었습니다.

처음 설치할 때는 README의 설치 명령을 사용하세요. 터미널을 여는 방법부터
안내하며, 사용자용 배포본을 자동으로 내려받아 설치합니다. GitHub의
**Code → Download ZIP**은 개발 소스를 받는 기능입니다.

v0.3.0은 새 설치만 지원합니다. 기존 설치 폴더가 있으면 그 안의 자료를
보호하기 위해 중단합니다. 자료를 유지하며 새 버전으로 교체하는 업데이트는
아직 제공하지 않으므로, 업데이트 목적으로 기존 설치본을 지우지 마세요.
