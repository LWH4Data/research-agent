# 시각 검토 일시 정지·재개 가이드 캡처 · 2026-10-06

## 반영 범위

사용자가 제공한 ALBERT·ELECTRA·DeBERTa 실제 요청·응답 8장을 웹 `#/organize`의
`시각 검토를 잠시 멈추고 이어서 하려면`에 넣었다. 바깥 안내와 네 단계는 처음에
접혀 있다. 저장·검토 시작 확인 → 지정 문서 검토 일시 정지 → 남은 검토 재개 →
현재 상태 확인 순서이며, 각 단계에 복사 문장과 요청·응답 두 장을 둔다.

폴더에서 저장한 PDF와 첨부한 PDF에 같은 제어를 사용할 수 있으며 예시 문서 이름을
사용자의 문서로 바꾸도록 안내한다. 전체 자료실 보류는 개별 문서 재개로 해제되지
않는다는 기존 계약과 시간·페이지 기준은 안내이고 중단은 사용자가 결정한다는
정책을 유지했다. 실제 작업을 자동으로 다시 접수하는 페이지가 아니라 사용 안내다.

## 캡처가 보고한 상태와 해석

- 저장 응답: PDF 3개의 본문 저장·추출 완료, 실패 파일 없음, 백그라운드 시각 검토 시작·진행 중.
- 일시 정지 응답: 실행 프로세스 실제 종료 확인, 본문·완료 결과 유지. ALBERT 4쪽 완료·6쪽 남음, ELECTRA 0쪽 완료·13쪽 남음, DeBERTa 0쪽 완료·16쪽 남음. 다른 문서에는 영향 없음.
- 재개 응답: 남은 시각 검토가 백그라운드에서 재개되어 진행 중. 전체 검토 완료로 설명하지 않는다.
- 현재 상태 응답: **선정된 시각 검토 대상** 기준 ALBERT 9/10쪽 확인·10쪽 추가 확인, ELECTRA 8/13쪽 확인·14–18쪽 진행/대기, DeBERTa 8/16쪽 확인·16–23쪽 진행/대기. PDF 전체 쪽수와 구분한다.

ALBERT 10쪽의 Table 10 UPM 행 RACE 열 대시가 **추출문에서** 빠졌고
`evaluation benchmark` OCR 인식 문제와 표 열 정렬을 추가 확인해야 한다고
보고한다. 원본 표 자체의 오류나 교정 완료로 서술하지 않는다. 진행·대기는 오류
확정과 다르며, 추가 확인은 기존 `추가 검토가 필요하다고 나오면?` 안내로 이어진다.

위 내용은 제공된 화면의 보고를 설명한다. 이번 가이드 작업에서는 개인 라이브러리나
실행 상태를 다시 조회하지 않았고, 저장·중단·재개·추가 검토를 실행하거나 원본 PDF와
저장 자료를 변경하지 않았다. 영어 안내도 한국어 실제 화면임을 밝히며 동일한 상태를
설명한다. 마지막 이미지는 최종 완료 결과가 아니다.

## 구현과 검증

`renderFollowUp`에 선택적인 복사 문장·결과·이미지와 중첩 후속 안내를 지원했다.
그룹에 없는 프롬프트나 캡처를 빈 프레임으로 만들지 않는다. 기존 갱신·추가 검토
안내는 유지하며 모든 단계의 복사 ID를 구분했다. CSS와 제품 실행 코드는 바꾸지
않았다. `index.html`의 두 스크립트 캐시는 `20261006-review-control-captures`로
갱신했다.

- `node --check docs/site/app.js`, `node --check docs/site/content-en.js` 통과.
- `scripts/check_guides.py` 통과: v0.4.0 한글·영문·웹 설치 명령 일치.
- `git diff --check` 통과.
- 읽기 전용 독립 검토에서 제공 원본·보존 PNG·SVG 내장 PNG 8장의 바이트 및
  manifest 확인 값·viewBox 일치, 내용 보존과 시간·아이콘 제외를 확인했다.
- 독립 정적 한영 렌더 검사에서 undefined·빈 캡처 프레임·복사 ID 중복 0건,
  기존 갱신/추가 검토 안내 보존, 바깥 안내와 네 단계의 기본 접힘을 확인했다.
- 실제 브라우저에서 한글·영문 1280 × 720 및 390 × 844의 가로 넘침 없음,
  이미지 8장 로딩과 크게 보기 링크 8개를 확인했다. 한영 각 4개 복사 문장의
  클립보드 일치를 확인했다. 임시 viewport는 기본값으로 돌렸다.
- 독립 검토 지적에 따라 한영 대체 텍스트에서 누락 위치를 원본 표가 아닌 추출문으로
  명시했다. 한국어 새로고침 후 실제 DOM 반영을 확인했다.
- 브라우저 확인 화면은 `/private/tmp/research-agent-review-control-guide-desktop.png`,
  `/private/tmp/research-agent-review-control-guide-desktop-result.png`,
  `/private/tmp/research-agent-review-control-guide-mobile.png`에 저장했다.
