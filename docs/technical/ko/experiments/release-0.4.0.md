# 0.4.0 가이드·배포 검증 · 2026-10-06

[현재 상태](../ROADMAP.md#current-work) · [배포 절차](../releases.md)

## 변경 범위

폴더 확인 후 자동 저장과 시각 검토 수명 관리는 이미 구현된 변경이다. 이번
작업은 한국어·영어 웹 가이드, README·영문 사용자 안내, 배포 설명과 버전을
0.4.0에 맞춘다. 공개 가이드의 구버전/개발본 분기를 제거하고, 폴더 상태 확인과
이후 새·변경 PDF 갱신 요청을 구분했다. 연결 가이드의 빈 프레임은 승인된
설치 캡처 3장으로 채웠다. 원본 픽셀은 변경하지 않았으며 이전 화면의 비활성
버튼과 선택 목록만 보이는 크롭의 한계를 캡션에 남겼다.

`pyproject.toml`을 버전 원본으로 사용하고 `uv lock`으로 잠금 파일을 재생성했다.
오프라인 캐시 부족으로 첫 생성은 실패했으며 정상 네트워크 실행은 성공했다.
의존성은 그대로이며 잠금 파일은 제품 버전만 변경됐다.

배포 압축 검사는 `.github/workflows/release-check.yml`의 Python을 변경 없이
임시 staging에서 실행했다. lifecycle 검사는 임시 실행 어댑터에서 자체 압축
생성만 실제 압축 경로로 대체하고 테스트 본문은 그대로 실행했다. 선택/재선택
범위만 저장되며 미선택 위치는 제외되고, 전체 검토 보류 아래 페이지 시도 0과
원본 fixture의 inode·mode·mtime·해시 보존을 확인했다. 모델 실행은 가짜 Codex
프로세스다. 설치·제거는 폐기 가능한 HOME과 Trash만 사용한다.

설치 시험의 첫 실행은 샌드박스 DNS 차단으로 실패했다. 해당 시험만 추가
실행 권한으로 재시도해 통과했다. 처음 실패를 제품 설치 실패로 해석하지 않는다.
README·영문 안내에 선택창 포커스 문장을 마지막으로 추가한 뒤 최종 압축을
재조립했다. 최종 압축의 파일 내용·권한·매핑·SHA-256과 정확한 제품 파일 검사
1개가 통과했다. 앞선 설치·lifecycle 9개와 이 내용 검사는 구분하며, 문구만
변경되어 기능 검사를 반복하지 않았다. 최종 CI는 게시 압축을 새로 검사한다.

## 보장하지 않는 것

전체 검사에서 실제 Codex/권한 조건 검사 3개, 실제 압축 경로가 필요한 2개,
대소문자 구분 파일시스템이 필요한 2개가 건너뛰어졌다. 실제 압축 검사 3개는
별도 실행에서 모두 통과했으며,
실제 구독 모델·알림 수신·새 Mac 환경의 Codex 권한/응답은 이번에 시험하지 않았다.
개인 설치·자료실·스킬 등록과 사용자의 원본 PDF는 변경하지 않았다.

시각 검토 완료는 요청된 후보 페이지의 확인 기록이다. PDF 모든 페이지의
해석 정확도나 누락 없는 후보 선별을 인증하지 않는다. 웹 결과 캡처의 숫자와
보존 안내는 사용자가 제공한 응답의 보고이며 이번 실제 저장소 조회가 아니다.
영어 문구는 한국어 캡처를 설명한다.
