# 설치·폴더 안내창 한영 지원 · 2026-10-06

## 요청과 범위

사용자는 영문 가이드 화면을 캡처하기 전에 앱의 안내창에도 한영 지원을 추가하도록
요청했다. 기존 네이티브 AppKit 선택 흐름을 유지하며 설치 완료 안내, 폴더 선택 설명,
확인 목록·빈 상태·선택 개수·버튼·관련 오류와 설치 후 안내 문구를 번역한다.

현재 공개 제품 v0.4.1의 안내창은 한국어 고정이다. 이번 변경은 개발 소스에서
구현·자동 검증을 완료했으며, 개인 설치본과 공개 배포 파일은 바꾸지 않았다.

## 언어와 경계

`auto`는 macOS `NSLocale.preferredLanguages`의 첫 지원 언어를 사용한다.
명시적인 `ko` 또는 `en` 요청을 우선하고, 탐지 실패나 지원 언어가 없으면 영어를
사용한다. 설치 bootstrap의 `LC_ALL=C`가 Mac의 실제 선호 언어를 가리지 않도록
고정 Foundation JXA와 제한된 응답·타임아웃을 이용한다.

호스트 helper와 공개 실행기에 `--language auto|ko|en`을 전달한다. 언어는 화면을
표시하는 데만 사용하며 등록·저장·시각 검토 명령과 intake 사양에는 포함하지 않는다.
소유 root·Codex·sandbox 옵션은 기존 실행기에서 고정한다. 언어를 강제로 설정하는
환경 변수 래퍼, 새 저장 설정이나 권한 확장은 추가하지 않는다.

설치 안내가 결정한 언어를 다음 폴더 선택창에도 전달한다. 선택 목록은 메모리에서만
유지되며, 안쪽 선택창 취소는 목록을 보존하고 전체 확인창 취소는 등록·저장을
시작하지 않는다. 원본 경로와 파일은 변경하지 않는다.

## 실제 화면 확인과 한계

저장 명령에 연결하지 않은 생성 스크립트로 미리보기를 준비했다. 임시 앱을 화면
제어 도구가 선택하지 못해 기본 Script Editor에서 영문 설치 안내를 실행했다.
`Research Agent is installed.`, 본문, `Later / Choose folders`가 모두 보이며 잘림이
없음을 실제 창과 캡처에서 확인했다. 이 캡처는 개발 컴포넌트 확인용이며 설치
완료 화면이나 공식 영문 가이드 사용 사례로 꾸미지 않는다.

영문 폴더 확인창은 Script Editor가 JXA를 보조 스레드에서 실행해 AppKit의
주 스레드 조건 오류를 냈다. 해당 호스트는 제품의 `osascript` 실행 경로가 아니므로
제품 오류나 실제 폴더창 검증 성공으로 간주하지 않는다. 한영 폴더창은 자동·모의
검증과 컴파일을 완료했지만 실제 영문 빈 목록·선택 목록·폴더 선택창의 시각 확인,
설치 직후 포커스와 다른 Mac 검증은 후속 작업이다. 미리보기 프로세스와 임시 문서는
닫았고, 개인 라이브러리·설치·OS 언어 설정은 바꾸지 않았다.
