# 폴더 연결창 최신 캡처 · 2026-10-06

## 빈 목록 화면 교체

사용자가 제공한 최신 빈 폴더 초안 화면을 `시작하기`의 폴더 선택 1단계와
`PDF 폴더 연결하기`에 함께 반영했다. 비활성 버튼도 현재 문구인
`연결하고 PDF 저장하기`이며, 한영 네 캡션에서 이전 문구라는 주석을 제거했다.
목록은 이번에 추가할 폴더의 빈 초안이며 기존 연결이나 저장 자료가 없다는 뜻으로
설명하지 않는다. 제품 동작·설치본·원본 PDF·라이브러리 상태는 변경하지 않았다.

## 남은 작업과 게시 상태

빈 목록에 이어 사용자가 제공한 최신 다중 선택창도 반영했다. 현재 필수 캡처는
모두 확보했다. 아래 최종 점검을 완료했으며 로컬 가이드가 게시 가능한 상태다.
아직 커밋·푸시하지 않았다. 제품 버전·공개 v0.4.0 태그는 유지한다.
ALBERT 추가 확인 결과와 실제 영문 화면은 선택적인 후속 보완이다.

- 표시 파일: `docs/site/assets/screenshots/folder-selection-20261006.png`
- 크기: 1738 × 942

  잘린 폴더 이름을 특정 폴더명으로 추정하지 않는다.
- 시작하기·연결 안내의 한영 네 캡션/alt에서 이전 크롭·버튼 누락이라는 설명을

  기존 가이드 표시로 강조하고 원본 크기로 여는 크게 보기 링크를 추가했다.
- 최종 두 JS 캐시는 `20261006-folder-picker-captures`다.
- 독립 읽기 전용 검토에서 원본 일치·확인 값·크기·네 문구·강조·크게 보기·캐시를
  확인했다. 한영 76개 캡처 참조에 연결 누락이 없으며 기존 빈 목록·갱신·검토
  제어 8장·추가 검토 안내도 보존됐다. 필수 캡처 누락은 0개다.
- 실제 브라우저에서 한영 9개 경로(둘러보기, 시작하기 3단계, 연결, 첨부, 폴더

  확인했다. 총 36개 경로/언어/폭 조합에서 가로 넘침·이미지 누락·빈 캡처 영역이
  없었다. 데스크톱에서는 undefined 문구·중복 DOM ID도 없었다.
  시작하기 3단계 새 이미지와 버튼 강조를 시각적으로 확인했다.
- JavaScript 두 파일 구문·한영웹 가이드 일치·변경 형식 검사를 통과했다.
  실제 저장·검토/모델 호출 없이 웹 표시만 확인했으므로 제품 실행 검증으로
  설명하지 않는다. 기존 실제 복사 검증은 갱신·제어 캡처 기록을 참조한다.
