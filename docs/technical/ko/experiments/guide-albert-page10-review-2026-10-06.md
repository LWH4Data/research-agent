# ALBERT 10쪽 추가 검토 가이드 캡처 · 2026-10-06

## 반영 범위

사용자가 제공한 ALBERT 10쪽 추가 검토 요청과 처리 결과 한 장을 웹
`#/organize`의 `추가 검토가 필요하다고 나오면?` 안내 아래 별도 예시로 넣었다.
`organize-review`의 `followUps`에 `albert-page10-review`를 추가하고 처음에는
접힌 상태로 표시한다. 문서 이름과 PDF 첫 장부터 센 페이지 번호를 자기 자료에
맞게 바꾸도록 설명하며, 한글·영문 복사 문장과 실제 요청·결과 화면을 제공한다.

앞선 ALBERT 9/10쪽 상태와 추가 확인 필요 기록을 당시의 상태로 보존한다.
기존 BERT 15쪽·Auto-Encoding Variational Bayes 14쪽 처리 예시와 다른 문서의
진행·대기 기록도 유지했다. 새 예시가 이 기록들을 전체 완료로 바꾸지는 않는다.

## 캡처가 보고한 결과와 해석

요청은 저장된 ALBERT PDF의 10쪽만 확인하고, 추가 확인이 남았다면 그 페이지만
다시 검토해 저장하도록 지정한다. 이미 검증됐으면 저장된 결과를 보여 달라는
조건도 있어 같은 페이지를 불필요하게 반복 처리하도록 안내하지 않는다.

응답은 **ALBERT PDF 10쪽만** 다시 검토해 검증 완료로 저장했다고 보고한다. Table 10 열 순서와 Ensembles UPM 행을 원본과
대조하고, 추출문에서 빠졌던 RACE 열 마지막 대시와 `evaluation benchmark` OCR
교정 내용을 시각 검토 노트에 기록했다고 설명한다. 원본 표의 오류를 고쳤다는
뜻이 아니며, 기본 추출 본문과 기존 검토 결과는 유지했다.

해당 페이지에서 여전히 확인하지 못한 부분은 없다고 보고하지만 완료 범위는
요청한 10쪽이다. 다른 문서나 PDF 전체의 완료 결과로 확장하지 않는다.
영어 가이드도 같은 한국어 실제 캡처임을 밝히고 동일한 범위를 설명한다.

이번 작업은 제공된 화면을 사용 가이드에 반영한 것이다. 개인 라이브러리,
검토 상태와 원본 PDF를 별도로 조회하지 않았으며 저장·추가 검토·모델 호출을
실행하지 않았다. `verified`의 저장 계약과 해석 한계는
[PDF 변환과 검토 상태](../pdf-conversion.md#검토-상태의-의미)에 따른다.

## 구현과 검증

`docs/site/app.js`의 기존 `renderFollowUp`으로 예시를 표시하고,
`docs/site/content-en.js`에 한영 설명을 맞췄다. `index.html`의 두 스크립트 캐시는
`20261006-albert-page10-review`로 갱신했다. CSS와 제품 실행 코드는 바꾸지 않았다.

- 최종 `node --check docs/site/app.js`와
  `node --check docs/site/content-en.js`를 통과했다.
- `.venv/bin/python -B scripts/check_guides.py`를 통과했다. v0.4.1 한글·영문·웹
  설치 명령이 일치하며 제품 버전은 유지한다.
- `git diff --check`를 통과했다. 런타임 변경이 없는 캡처·문구 추가이므로
  이 후속 패치를 위해 전체 제품 테스트를 반복하지 않았다.
- 실제 브라우저에서 한글·영문 × 데스크톱·모바일 네 조합을 확인했다.
  viewport override는 1280 × 720과 390 × 844이며, 현재 앱 배율을 반영한
  실제 DOM CSS 영역은 각각 1163 × 654와 354 × 767이었다.
- 모든 조합에서 두 이미지가 정상 로딩됐고 자연 크기는 1150 × 310과
  1640 × 375였다. 가로 넘침은 없으며, 한영 모두 복사 ID 중복과
  `undefined` 출력은 0건이었다. 예시의 기본 접힘을 직접 확인했다.
- 각 언어에서 복사 버튼을 한 번씩 눌러 DOM 프롬프트와 브라우저 클립보드가
  완전히 일치함을 확인했다. 사용자 클립보드는 원래 내용으로 복원했다.
- 요청·결과의 작업 시간과 하단 아이콘은 표시하지 않으며, 새 화면의 본문이
  잘리지 않음을 확인했다. 모바일에는 크게 보기 링크를 제공한다.
- 확인 화면은 `/private/tmp/research-agent-albert-page10-guide-desktop.png`,
  `/private/tmp/research-agent-albert-page10-guide-mobile.png`,
  `/private/tmp/research-agent-albert-page10-guide-en-desktop.png`에 저장했다.
  임시 viewport 설정을 해제하고 한국어 미리보기를 유지했다.

## 게시 상태와 다음 단계

제품 사전 출시와 기존 웹 가이드의 v0.4.1 배포는 완료되어 있다. 이번 ALBERT
후속 예시는 로컬 반영 상태이며 아직 커밋·푸시하지 않았다. 런타임 버전과 기존
공개 태그를 바꾸거나 배포 파일을 교체하지 않는다.

로컬 반영과 브라우저 확인을 완료했다. 다음 게시 시 이 후속 패치의 커밋·푸시와
Pages 배포 확인이 필요하다. 실제 영문 화면은 선택적 후속 보완이며, 기존 사용자의
설치 업데이트 절차는 별도 제품 개발 범위다.
