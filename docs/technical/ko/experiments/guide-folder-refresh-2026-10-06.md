# 연결 폴더의 새 PDF 갱신 가이드 캡처 · 2026-10-06

## 반영 범위

사용자가 새 PDF를 연결 폴더에 추가하고 갱신을 요청한 실제 화면을 제공했다.
웹 `#/organize`의 `폴더에 PDF를 추가하거나 바꿨다면` 접힘 안내에 요청과 결과
두 이미지를 넣고 한글·영문 복사 문장을 실제 요청과 맞췄다. 새로 저장한 문서
이름과 기존 문서 유지 수, 실패·검토 상태와 검토 페이지 수의 범위를 확인하도록
안내한다. 기존 레이아웃과 렌더러, 제품 코드·버전은 변경하지 않았다.

- 결과 표시: `folder-pdf-refresh-result.svg`, `viewBox="86 397 1490 370"`

SVG는 원본 PNG 전체를 그대로 내장하고 표시 영역만 지정한다. 원본 픽셀은
수정·재샘플링하지 않았다. 요청 말풍선과 결과 본문을 온전히 보여 주면서
작업 시간·구분선·하단 액션 아이콘을 제외했다. 기존 크게 보기 링크를 사용한다.

## 화면이 보고한 결과와 한계

화면은 FastBERT, BERT-of-Theseus, SqueezeBERT PDF 3개 신규 저장과 기존 9개
변경 없이 유지, 저장 실패·원본 누락 없음을 보고한다. 시각 검토는 **현재 요청
범위에서** 109쪽 검증 완료·8쪽 진행 또는 대기이며, 추가 확인이 필요한 페이지는
현재 없고 백그라운드 검토가 계속된다고 안내한다.

이는 사용자 제공 화면의 결과 설명이다. 이번 가이드 반영에서 실제 라이브러리나
작업 상태를 다시 조회하지 않았으며 원본 PDF·저장 자료를 변경하거나 구독 모델을
호출하지 않았다. 109쪽을 신규 세 문서만의 페이지 수로 설명하지 않는다.
영문 안내에서도 한국어 실제 화면임을 밝히고 같은 범위와 상태를 유지한다.

## 다음 캡처용 새 PDF 준비

사용자가 완료된 작업을 반복하지 않고 새로운 PDF로 중단·재개를 촬영하도록
바탕화면에 새 파일을 준비해 달라고 요청했다. 다음 원본을 공식 arXiv에서
다운로드했다. 파일명의 연도는 최초 공개 연도이며 내려받은 파일은 현재 저자
공개 수정본이다.

| 파일 | 공식 원문 | 페이지 | 표시 확인 |
| --- | --- | --- | --- |
| `01_ALBERT_2019.pdf` | [ALBERT](https://arxiv.org/abs/1909.11942) | 17 | 4쪽 그림 |
| `02_ELECTRA_2020.pdf` | [ELECTRA](https://arxiv.org/abs/2003.10555) | 18 | 2쪽 그림 |
| `03_DeBERTa_2020.pdf` | [DeBERTa](https://arxiv.org/abs/2006.03654) | 23 | 6쪽 표 |

목적지: `/Users/lwh/Desktop/research-agent-review-control-test`.
세 PDF만 넣었고 기존 파일은 덮어쓰지 않았다. PDF 헤더·비암호화·제목·페이지
수와 그림/표 캡션을 확인했다. Poppler로 해당 페이지를 렌더링해 정상 표시를
확인하고, 최종 복사본과 다운로드 원본의 SHA-256 일치를 검사했다.

읽기 전용 관리 에이전트는 개인 launcher의 `source-list` 및
`search --scope pdf --limit 200`을 사용했다. 모든 검색은 추가 결과 없음으로
반환됐고 후보 논문 자체의 문서 경로는 없었다. ALBERT와 ELECTRA의 기존 PDF
참고문헌 언급은 별도 저장으로 세지 않았다. DeBERTa는 검색 결과가 없었다.
이는 검색 결과 범위의 확인이며 별도 전용 문서 목록 명령으로 완전 목록을
검증한 것은 아니다. 바탕화면 자체나 새 목적지의 상위 위치는 등록된 자료원이
아니며 등록 위치는 `research-agent-test1`·`test2`·`test3`뿐이었다.

이번 준비에서는 import·sync·시각 검토를 실행하지 않았다. 사용자가 저장 후
검토 진행 중인 세 문서만 중단하고, 저장 결과를 유지하며 남은 검토를 재개하는
실제 화면을 다음 단계에서 제공한다. 전체 보류가 있다면 개별 문서 재개로
해제되지 않으므로 답변에서 그 상태를 구분해야 한다. 실제 캡처와 재개 성공은
아직 검증하지 않았다.
