# Research Agent

[웹 사용 가이드](https://lwh4data.github.io/research-agent/) · [English installation guide](docs/en/user-guide.md)

흩어져 있는 PDF와 중요한 연구 대화를 정리하고, 필요할 때 Codex에서 다시
찾아볼 수 있게 도와주는 개인 연구 자료실입니다.

> **지원 환경**
>
> 현재 공식적으로 지원하고 검증한 환경은 **macOS**입니다. Windows와
> Linux는 아직 공식 지원하지 않습니다.

> **권장 구독**
>
> **ChatGPT Pro 5x**를 권장합니다. ChatGPT Plus에서도 사용할 수 있지만,
> PDF가 많거나 수식·표·그림을 확인할 페이지가 많으면 구독 사용량에 더 빨리
> 도달할 수 있습니다. 구독별 사용량은 달라질 수 있으므로 현재 기준은
> [OpenAI 요금 및 사용량 안내](https://learn.chatgpt.com/docs/pricing)에서
> 확인하세요.

> **Chrome에서 사용법을 바로 물어볼 수 있습니다**
>
> Chrome에서 이 GitHub 페이지를 보고 있다면 브라우저 상단의
> **Gemini에게 물어보기(Ask Gemini)**를 누르고 다음처럼 질문해 보세요.
>
> - “이 페이지를 기준으로 Research Agent 설치 방법을 단계별로 알려줘.”
> - “Research Agent로 영어 PDF를 한국어로 검색할 수 있어?”
> - “원본 PDF를 보호하면서 사용하는 방법을 알려줘.”
>
> Gemini in Chrome은 현재 보고 있는 페이지를 참고해 답변합니다. 계정이나
> 지역에 따라 이 기능이 아직 표시되지 않을 수 있습니다. 자세한 조건은
> [Gemini in Chrome 안내](https://support.google.com/gemini/answer/16283624?hl=ko)에서
> 확인할 수 있습니다.

- PDF를 한 폴더로 옮길 필요가 없습니다.
- 영어 PDF도 한국어로 질문할 수 있습니다.
- 사용자가 선택한 대화를 PDF와 함께 검색할 수 있습니다.
- 원본 PDF를 수정하거나 삭제하는 기능은 제공하지 않습니다.
- 별도의 OpenAI API 키 없이 로그인된 Codex 구독을 사용합니다.

> Research Agent는 현재 프로토타입입니다. 중요한 원본은 평소 사용하던
> 위치와 백업에 그대로 보관하세요.

## 1. Research Agent 설치하기

### 이런 때 사용합니다

Research Agent를 처음 사용할 때 한 번만 설치합니다.
아래 명령은 **v0.3.0 사전 출시 버전**의 사용자용 배포본을 설치합니다.
GitHub의 **Code → Download ZIP**은 개발 소스이므로, 처음 사용할 때는
아래 설치 명령을 이용하세요. Git이나 별도 Python 설치는 필요하지 않습니다.

### 터미널에 입력하세요

터미널을 처음 사용한다면 다음 순서대로 진행하세요.

1. 키보드에서 `Command(⌘) + Space`를 누릅니다.
2. 화면에 검색창이 나타나면 `터미널`을 입력합니다.
3. 검색 결과에서 **터미널** 앱을 선택합니다.
4. 검은색 또는 흰색 터미널 창이 열리면 아래 명령 전체를 복사합니다.
5. 터미널 창을 클릭하고 `Command(⌘) + V`로 붙여 넣습니다.
6. 키보드의 `Enter`를 누르고 설치가 끝날 때까지 기다립니다.

```sh
(
  installer=$(mktemp) &&
  trap 'rm -f "$installer"' EXIT &&
  curl -q --proto '=https' --proto-redir '=https' --tlsv1.2 -fLsS \
    https://github.com/LWH4Data/research-agent/releases/download/v0.3.0/install-release.sh \
    -o "$installer" &&
  bash "$installer" --version 0.3.0
)
```

설치 파일을 자동으로 내려받고 검사한 뒤, 홈 폴더의 `research-agent`에
설치합니다. 직접 압축을 풀 필요는 없습니다. 해당 위치에 폴더나 파일이 이미
있으면 덮어쓰지 않고 중단합니다. 이 경우 기존 폴더를 삭제하지 말고,
표시된 메시지와 경로를 Codex에 알려주세요.

정상적인 설치 과정에서는 Mac 관리자 암호를 요구하지 않습니다. 예상하지 못한
암호 입력창이 터미널 안에 나타나면 암호를 입력하지 말고, 붙여 넣은 명령이 위
내용과 같은지 먼저 확인하세요.

설치가 끝나면 **폴더 선택하기**와 **나중에 하기** 버튼이 있는 안내창이
나타납니다. 지금 폴더를 연결하거나, 나중에 하기를 누르고 바로 Codex에서
시작해도 됩니다. 창을 닫거나 폴더 선택을 취소해도 설치는 완료된 상태입니다.
선택창에서 `Command(⌘)` 키를 누른 채 폴더를
클릭하면 여러 폴더를 한 번에 연결할 수 있습니다. 다른 위치의 폴더는 나중에
계속 추가할 수 있습니다.

안내창이 열리지 않으면 설치 후 아래의 [폴더 연결 방법](#3-pdf가-있는-폴더-연결하기)을
사용하세요. 자동 실행처럼 입력을 받지 않는 설치에서는 안내창을 띄우지 않습니다.

설치가 끝나면 열려 있던 Codex 앱·CLI·IDE를 완전히 종료한 뒤 다시 엽니다.
별도의 OpenAI API 키는 필요하지 않습니다.

## 2. Full access를 사용하지 않기

Research Agent를 사용할 때는 현재 Codex 작업에 **Full access를 주지
마세요.** 평소 사용하던 `Ask for approval`이나 `Approve for me`는 그대로
사용할 수 있습니다.

Research Agent는 지금 사용하던 Codex 대화에서 호출합니다. 별도의 대화를
열 필요는 없습니다. 내부 작업 에이전트에는 읽기 전용 기본 설정이 있고,
저장은 원본 폴더에 쓸 수 없는 전용 도구를 통해 처리합니다.

이 제한이 현재 Codex 대화 전체의 권한을 바꾸지는 않습니다. 현재 대화의 권한
설정이 내부 에이전트의 기본 설정보다 우선할 수도 있습니다. 따라서
`Full access`를 사용하지 않는 것만으로 원본 보호가 모두 보장되지는 않습니다.

현재 Codex 프로젝트 안에 원본 PDF 폴더가 있으면 기본 권한에서도 그 프로젝트
파일을 수정할 수 있습니다. 이 경우처럼 원본에 대한 가장 강한 보호가 필요할
때는 해당 작업만 읽기 전용으로 전환하세요.

`Approve for me`는 필요한 승인 요청을 자동으로 검토하는 방식이며,
원본 폴더를 읽기 전용으로 만드는 설정은 아닙니다. Research Agent는 원본에
대한 쓰기 권한을 요청하지 않도록 지시되어 있습니다. 접근이 막히면 쓰기 권한을
넓혀 해결하지 않고, 중단하거나 보류한 뒤 원인을 안내해야 합니다.

- Codex 앱·IDE: 입력창 아래의 권한 메뉴에서 권한을 선택합니다.
- Codex CLI: `/permissions`에서 현재 권한을 확인하거나 변경합니다.

## PDF를 대화에 첨부해서 저장하기

PDF 몇 개로 시작한다면 폴더를 먼저 연결할 필요가 없습니다. Codex 대화에
PDF를 한 개 또는 여러 개 첨부하고, `@` 메뉴에서 **Research Agent**를
선택한 뒤 이렇게 말하세요.

```text
첨부한 PDF 3개를 정리하고 공통된 내용을 찾아줘.
```

Research Agent는 첨부한 PDF들을 폴더 등록 없이 기존 연구 자료 저장소에
추가합니다. 내부에 PDF 사본과 검색할 내용을 보관하고, 원본은 옮기거나
수정하지 않습니다. 텍스트 정리가 끝나면 다른 대화에서도 이 자료를 검색할 수
있습니다. 수식·표·그림이 있는 페이지의 확인은 뒤에서 계속 진행됩니다.
중단됐다면 “저장한 PDF 정리를 이어서 해줘”라고 말하세요.

- Research Agent에게 첨부 PDF로 연구 작업을 요청하면 별도의 저장 요청 없이
  저장소에 추가됩니다. 현재 대화에서만 사용하고 싶다면 “저장하지 말고
  설명해줘”라고 말하세요. PDF를 첨부만 해두면 자동 저장되지 않습니다.
- 여러 PDF 중 하나를 읽을 수 없어도 나머지 결과는 보관하고, 어떤 파일에
  문제가 있었는지 알려줍니다.
- 같은 내용의 PDF를 다시 저장하면 기존 항목을 사용합니다. 파일 이름이 달라도
  내용이 같으면 처음 저장한 이름을 유지합니다.
- 내용이 달라진 PDF를 다시 첨부하면 별도 자료로 저장합니다. 첨부 저장은 원본의
  이후 변경을 자동 반영하지 않으므로, 계속 바뀌는 자료는 폴더를 연결하세요.
- 폴더에서 정리한 PDF와 별도로 첨부해 저장한 PDF는 각각 관리됩니다.
- 암호가 걸린 PDF와 256 MiB를 넘는 PDF는 현재 첨부 저장을 지원하지 않습니다.

사용 중인 Codex 환경에서 첨부 파일을 직접 읽을 수 없다면 저장되지 않았다고
안내합니다. 이때는 해당 PDF의 컴퓨터 내 위치를 알려 주거나 폴더를 연결하세요.

## 3. PDF가 있는 폴더 연결하기

### 이런 때 사용합니다

기존 폴더에 있는 PDF를 옮기지 않고 Research Agent에서 찾고 싶을 때
사용합니다. PDF가 논문일 필요는 없습니다.

### Codex에 이렇게 말하세요

```text
@Research Agent 내 PDF가 있는 폴더를 연결해줘.
```

Codex가 알려주는 명령을 일반 터미널에서 실행하면 Finder 폴더 선택창이
열립니다. 연결할 폴더를 선택하세요. 같은 화면에 보이는 여러 폴더는
`Command(⌘)` 키를 누른 채 하나씩 클릭한 뒤 선택 버튼을 누르면 한 번에
추가됩니다. 서로 다른 위치에 있는 폴더도 같은 방법으로 계속 추가할 수 있습니다.

직접 선택창을 열고 싶다면 다음 명령을 사용할 수 있습니다.

```sh
bash "$HOME/research-agent/add-source.sh"
```

경로를 알고 있다면 여러 폴더나 PDF의 경로를 함께 알려 주고 연결해 달라고
요청할 수도 있습니다.

```text
@Research Agent ~/Documents/광소자 연구 폴더를 연결해줘.
```

### 연결하면 어떻게 되나요?

- 선택한 위치만 기록하며, 이 단계에서는 PDF를 변환하지 않습니다.
- PDF는 원래 위치에 그대로 남습니다.
- 정리 결과는 `research-agent` 내부에 따로 저장됩니다.
- 원본 폴더에는 Markdown, 캐시, 숨김 파일을 만들지 않습니다.
- 이미 연결된 같은 폴더는 다시 추가되지 않습니다.
- 상위 폴더와 그 안의 하위 폴더를 함께 연결하려 하면 중복 스캔을 막기 위해
  등록을 중단합니다. 한 번에 선택한 위치 중 이런 충돌이 있으면 새 위치를
  일부만 등록하지 않습니다. 하위 폴더의 PDF까지 찾으려면 상위 폴더만 연결하세요.

### 연결을 해제하고 싶다면

```text
@Research Agent 연결된 PDF 위치를 보여줘.
```

```text
@Research Agent documents 위치의 연결을 해제해줘.
```

연결 해제는 앞으로 해당 위치를 확인하지 않게 할 뿐입니다. 원본은 삭제하지
않고, 이미 만들어진 검색 자료도 남아 계속 검색됩니다. 같은 위치를 다시
연결하면 확인을 재개합니다.

## 4. 새로운 문서 정리하기

연결한 폴더에 있는 PDF를 처음 정리하거나 새로운 PDF를 추가했다면 다음과
같이 요청하세요.

```text
@Research Agent 새로 추가된 문서를 정리해줘.
```

진행 상황은 현재 Codex 대화 안에 표시됩니다.

```text
2/3 문서를 정리하고 있어요
[██████░░░░] 26/42 · 62%
새로 정리됨 6개 · 문제 발생 1개
```

처음에는 연결된 위치의 PDF를 정리합니다. 이후에는 새로 추가되거나 변경된
PDF만 다시 처리하고, 변경되지 않은 PDF는 건너뜁니다.

수식·표·그림처럼 텍스트만으로 확인하기 어려운 페이지가 발견되면 필요한
페이지만 **백그라운드에서** 추가로 살펴봅니다. 텍스트 정리가 끝나면 곧바로
검색하거나 대화를 이어갈 수 있습니다. 확인 중인 그림이나 수식에 관한 설명은
검토가 끝날 때까지 미확인으로 표시합니다. 이미지 확인은 일반적인 문서
정리보다 오래 걸리고 Codex 구독 사용량을 더 사용할 수 있습니다.

진행 상황이 궁금하다면 같은 대화에서 이렇게 물어보세요.

```text
@Research Agent 수식과 그림 확인은 얼마나 진행됐어?
```

백그라운드 확인이 끝나거나 오류로 중단되면 **macOS 알림**을 받을 수
있습니다. 5분 안에 끝나는 작업은 완료 또는 오류 알림만 보내고, 5분 이상 이어지는
작업은 처리한 페이지가 25%·50%·75% 지점을 새로 지날 때 진행률도 알립니다.
알림의 처리 수에는 추가 확인이 필요한 페이지도 포함되며, 그 수는 따로
표시해 검증이 끝난 페이지와 구분합니다.

macOS 알림 설정이나 실행 환경에 따라 알림이 보이지 않을 수 있지만,
알림 실패로 문서 확인이 중단되지는 않습니다. Codex 대화에 새 메시지가
자동으로 추가되지는 않으며, 진행 상황은 위의 질문으로 언제든 확인할 수 있습니다.

작업이 중간에 종료되어도 이미 안전하게 저장된 결과는 유지됩니다. 다음에
같은 요청을 하면 저장된 상태를 확인한 뒤 남은 작업을 이어갑니다.

## 5. 저장된 자료 검색하기

Codex가 질문에서 한국어와 영어 핵심어를 골라 저장된 자료를 찾습니다. 정확한
문장을 기억하지 못해도 관련 주제와 용어를 사용해 질문할 수 있습니다.

```text
@Research Agent DBR cavity와 관련된 내용을 찾아줘.
```

```text
@Research Agent 저장된 영어 문서에서 attention mechanism의 장점을 찾아서 한국어로 설명해줘.
```

```text
@Research Agent 여러 문서에서 실리콘 포토닉스의 한계를 어떻게 설명하는지 비교해줘.
```

Research Agent는 PDF에서 정리한 내용과 저장된 대화를 함께 검색합니다.
답변할 때는 PDF 근거, 사용자가 저장한 생각, 이전 Codex 설명을 구분하고
가능한 경우 원본 경로와 페이지도 함께 알려줍니다.

백그라운드 작업이 중단되어 검토가 대기 중이라면 다음처럼 요청하세요.

```text
@Research Agent 검토 대기 중인 수식, 표, 그림 페이지를 확인해줘.
```

## 6. 중요한 대화 저장하기

### 이런 때 사용합니다

Codex와 논의한 연구 아이디어나 실험 설계를 나중에 다시 찾고 싶을 때
사용합니다.

```text
@Research Agent 지금 대화에서 실험 설계에 관한 부분을 저장해줘.
```

Research Agent는 다음 중 어느 범위를 저장할지 먼저 묻습니다.

1. 현재 주제
2. 이번 대화 전체
3. 사용자가 직접 설명한 범위

범위를 선택하면 해당 대화를 연구 메모로 저장합니다. 확인할 수 없는 과거
대화를 임의로 복원하지 않으며, 확인 가능한 내용만 저장하고 빠진 범위를
표시합니다.

저장한 대화는 PDF와 함께 검색할 수 있습니다.

```text
@Research Agent 지난번에 내가 굴절률 보정에 관해 뭐라고 했지?
```

## 7. 저장한 대화 관리하기

### 목록 확인

```text
@Research Agent 내가 저장한 대화 목록을 보여줘.
```

### 정리 정보 수정

```text
@Research Agent 굴절률 보정 대화의 요약과 태그를 수정해줘.
```

수정할 수 있는 것은 제목, 요약, 태그처럼 검색을 위한 정리 정보입니다.
저장된 사용자 발언 원문과 저장 범위는 바꾸지 않습니다. 원문이나 범위를
잘못 저장했다면 기존 기록을 삭제하고 올바른 범위로 다시 저장해야 합니다.

### 삭제

```text
@Research Agent 지난주에 저장한 테스트 대화를 삭제해줘.
```

비슷한 기록이 여러 개라면 Research Agent가 삭제할 기록을 먼저 묻습니다.
삭제되는 것은 Research Agent 안의 해당 대화 기록뿐입니다. 실제 Codex 대화,
PDF, 다른 저장 기록에는 영향을 주지 않습니다.

> 현재 삭제한 대화 기록을 복구하는 기능은 없습니다.

## 다른 호출 방법

Codex 앱에서는 입력창에 `@`를 입력한 뒤 **Research Agent**를 선택하는
방법이 가장 쉽습니다.

Codex CLI 또는 IDE 확장에서는 `/skills`에서 `research-library`를 선택하거나
다음처럼 직접 호출할 수 있습니다.

```text
$research-library DBR cavity와 관련된 내용을 찾아줘.
```

`/research-library`라는 별도의 명령은 제공하지 않습니다.

## 자주 묻는 질문

### Research Agent가 원본 파일을 수정하나요?

정상적인 Research Agent 작업에는 원본 PDF를 수정·이동·삭제하는 기능이
없습니다. PDF를 읽어 만든 자료와 저장한 대화는 모두 `research-agent` 내부에
보관합니다.

내부 에이전트의 읽기 전용 기본 설정과 저장 도구의 제한은 현재 Codex 대화
전체의 권한을 바꾸지는 않습니다. `Ask for approval`이나 `Approve for me`를
사용할 수 있지만 Full access는 주지 마세요. 원본 PDF 폴더가 현재 프로젝트
안에 있다면 해당 작업을 읽기 전용으로 전환해 보호를 강화할 수 있습니다.
자세한 범위는 [권한 안내](#2-full-access를-사용하지-않기)를 참고하세요.

### PDF를 Research Agent 폴더로 옮겨야 하나요?

옮길 필요가 없습니다. 기존에 PDF가 보관된 폴더를 연결하면 됩니다. 서로
다른 위치에 있는 여러 폴더도 연결할 수 있습니다.

### 영어 PDF도 한국어로 찾을 수 있나요?

가능합니다. Codex가 한국어 질문에서 관련 영어 기술 용어를 골라 함께
검색합니다. 전문 용어를 알고 있다면 한국어와 영어를 같이 적어주면 더
정확하게 찾을 수 있습니다.

### 모든 PDF를 매번 다시 읽나요?

아닙니다. 처음 정리한 뒤에는 새로 추가되거나 변경된 PDF만 다시 처리합니다.

### 원본 PDF가 이동되거나 삭제되면 검색 자료도 사라지나요?

자동으로 사라지지 않습니다. 해당 원본을 찾을 수 없다고 표시하고, 이전에
만든 검색 자료는 보존합니다.

### Research Agent를 다른 Codex 프로젝트에서도 사용할 수 있나요?

가능합니다. 한 번 설치하면 현재 사용 중인 Codex 프로젝트에서
`@Research Agent`로 같은 개인 자료실을 사용할 수 있습니다. 각 Codex
프로젝트마다 별도의 자료실이 만들어지는 구조는 아닙니다.

### Research Agent의 자료가 자동으로 클라우드에 올라가나요?

별도 클라우드 저장소와 자동으로 동기화하는 기능은 없습니다. 정리한 Markdown,
검색 정보, 저장한 대화는 설치한 컴퓨터의 `~/research-agent` 안에 보관됩니다.
다만 Codex에 질문할 때 선택된 내용은 답변을 만들기 위해 로그인된 Codex
서비스에서 처리될 수 있습니다.

### 원하는 기능이 있는지 모르겠습니다

Codex에 다음처럼 물어볼 수 있습니다.

```text
@Research Agent 어떤 기능을 사용할 수 있어?
```

```text
@Research Agent 원본 파일을 건드리지 않고 PDF를 검색할 수 있어?
```

## 문제가 발생했나요?

### 폴더를 읽을 수 없다는 메시지가 나타납니다

먼저 해당 폴더가 현재 컴퓨터에 연결되어 있고 Finder에서 열리는지 확인하세요.
그다음 macOS의 `시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더`에서
Codex가 해당 위치를 읽을 수 있는지 확인합니다.

파일 접근은 macOS, Codex 실행 환경, 현재 권한 설정 등 여러 단계에서 막힐 수
있습니다. 오류가 계속되면 표시된 경로와 오류 메시지를 그대로 Codex에
알려주세요. 읽지 못한 위치의 이전 검색 자료와 검토 대기 상태는 삭제되지
않습니다.

### 연결된 폴더가 없다고 나옵니다

다음 명령으로 Finder 폴더 선택창을 열어 PDF가 있는 위치를 추가합니다.

```sh
bash "$HOME/research-agent/add-source.sh"
```

### 일부 페이지만 검토 대기 상태로 남아 있습니다

먼저 진행 상황을 물어보세요. 작업이 중단됐고 접근 권한이나 중단 원인을
해결했다면 다음과 같이 요청하세요.

```text
@Research Agent 검토 대기 중인 페이지부터 계속 진행해줘.
```

처음부터 모든 PDF를 다시 정리할 필요는 없습니다. 판독이 불확실하다고 표시된
페이지는 자동으로 끝없이 재검토하지 않으므로, 그 페이지를 따로 확인해 달라고
요청할 수 있습니다.

### 진행 표시를 먼저 보고 싶습니다

다음 명령은 실제 PDF나 저장 자료를 변경하지 않고 약 3초 동안 예시 진행
표시만 보여줍니다.

```sh
bash "$HOME/research-agent/demo-progress.sh"
```

## 업데이트

첫 배포본인 **v0.3.0은 새 설치만 지원합니다.** 기존 저장 자료를 유지하며
새 버전으로 교체하는 업데이트 절차는 아직 제공하지 않습니다.
설치 명령을 다시 실행해도 기존 폴더를 덮어쓰지 않습니다.

새 버전의 안내는 [Releases](https://github.com/LWH4Data/research-agent/releases)에서
확인할 수 있습니다. 배포본에는 Git 이력이 없으므로 `git pull`로 업데이트하지
않습니다. 기존 자료가 있는 설치본을 업데이트하려고 제거하거나 덮어쓰지 마세요.

## 제거

진행 중인 Research Agent 작업을 끝낸 뒤 다음 명령을 실행합니다.

```sh
bash "$HOME/research-agent/uninstall.sh"
```

화면에 표시된 설치 폴더를 확인하고 `y`를 입력하면 Codex 등록을 해제하고,
**그 설치 폴더 전체를 휴지통으로 옮깁니다.** 변환한 문서와 저장한 대화도 함께
옮겨집니다. 연결했던 원본 폴더와 PDF는 건드리지 않습니다.

설치 폴더와 저장 자료를 남기고 Codex 연결만 해제하려면 다음 명령을 사용합니다.

```sh
bash "$HOME/research-agent/uninstall.sh" --keep-files
```

다른 위치에 설치했다면 위 경로를 실제 설치 위치로 바꿉니다. 다른 설치본이
Codex에 연결되어 있거나 휴지통으로 옮길 수 없는 경우에는 이유를 표시하고
중단합니다. 외장 디스크처럼 사용자 홈과 다른 볼륨에 있는 설치본의 자동 제거는
아직 지원하지 않습니다. 제거 후에는 Codex를 완전히 종료했다가 다시 여세요.
